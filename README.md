# 🗂️ Custom Captcha 🔄 
This is a Custom Captcha web app built with HTML, CSS, and JavaScript. It generates a random 6-character captcha (letters + numbers), displays it on the page, and lets the user verify it by typing the value into an input field. A reload button allows generating a new captcha instantly.

## ➡️ Key Features
- Generates a random captcha on page load
- Includes Reload button to generate a new captcha
- Check button validates user input
- Shows success/error message
- Auto-refreshes captcha after a correct match

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
